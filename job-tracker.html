Quick start
1. Use the `Applications` tab to add a job, company, date, and status.
2. Add interview rounds as they happen, then update the job as you move forward.
3. Use `Summary` to see your pipeline over time.
4. Use `Coffee chats` to save networking conversations and follow-ups.
Saving your data
By default, Career Hub saves in your browser. When CSV sync is connected, it can also reload the CSV files so the HTML matches them.
Open the same HTML again in the same browser and your saved records should still be there.
If you switch browser, use private mode, or clear browser data, those records may not appear.
If you want the page to follow the CSV files, connect CSV sync once and use `Reload CSV` after editing the files.
Use `Export` regularly if you want a manual backup file.
CSV sync and Excel
Career Hub does not write directly into the Excel workbook. It writes CSV files, and Excel reads those CSV files.
Suggested sync folder: Detecting app folder...
Click `Connect CSV sync` in Chrome or Edge.
Choose the folder shown above. That is the app folder, not the Excel file itself.
After the first connection, Career Hub will try to remember the same sync folder in this browser.
Use `Reload CSV` if you update the CSV files outside the app and want Career Hub to show those changes.
When you finalize a record, click `Sync now` or confirm the sync status is green before you close the page.
After you save in Career Hub, the app updates `applications.csv`, `coffee-chats.csv`, and `interview-rounds.csv`.
Then open `JobTracker.xlsx` or press `Refresh All` in Excel to see the latest data.
Best practice
Use Career Hub as the main place where you enter and edit data.
Use Excel as your reporting and filtering view.
Keep the raw CSV files closed while syncing.
Use the search filters on `Applications` and the tree view in `Summary` to review progress quickly.
